# Архитектурные диаграммы проекта

Интерактивные визуальные диаграммы системы, созданные с помощью **Archify**:

1. **[Архитектура системы, CI/CD и бэкенда](system_architecture.html)** ([JSON-спецификация](system_architecture.json)):
   - **Контур CI/CD и автоматизации**: многоэтапная сборка в GitHub Actions (Go-бэкенд, Vue-фронтенд, релизный APK Android) и публикация в Docker Registry с автодеплоем через Docker Compose.
   - **Real-Time WebSockets (WSS)**: двунаправленная передача данных между мобильными клиентами / вебом через Nginx Ingress в Go Chi WebSocket Hub (живые статусы заказов, GPS-трекинг на карте, чат).
   - **Внутреннее устройство бэкенда**:
     - **Слой HTTP & WS**: Chi Router, WebSocket Hub, JWT-сессии, RBAC.
     - **Доменные сервисы**: `OrderService` (стейт-машина), `Shift & Geo Service` (GPS-смены, радиус), `AuthService`.
     - **Финансовое ядро**: `Ledger Service` (двойная запись денег, холды, комиссии, штрафы).
     - **Асинхронные воркеры**: `Workers Engine` (гео-матчинг каждые 5с, контроль SLA 30с, аукцион 1м, геокодинг).
   - **Хранение и телеметрия**: PostgreSQL DB, DaData Geo API, сбор метрик Prometheus `:9090` и дашборды Grafana `:3000`.
   - **Интерактивные режимы просмотра (Views)**: *Общая экосистема и CI/CD*, *CI/CD и автодеплой*, *WebSocket и живые заказы*, *Внутренняя структура бэкенда*, *Финансовый леджер*.

2. **[Жизненный цикл заказа и ветвления](order_lifecycle.html)** ([JSON-спецификация](order_lifecycle.json)):
   - **Магистраль выполнения (Golden Path)**: `Создан (холд)` ➔ `Поиск` ➔ `Назначен` ➔ `Выполнен (фотоотчет)` ➔ `Завершен (выплата и отзывы)`.
   - **Шлюзы аукциона и таймаута**: перевод неразобранных заказов в публичный аукцион ставок.
   - **Контроллер переназначения**: штрафы за срыв заказа исполнителем и возврат в поиск.
   - **Финальные исходы**: 100% возврат холда при отмене в поиске, удержание штрафа при поздней отмене, вердикт арбитража администратора.
   - **Интерактивные режимы просмотра (Views)**: *Основной путь*, *Аукцион и отмена по таймауту*, *Штрафы, споры и переназначение*.
