# Панель администратора (Admin Control & Operational Management)

Документ содержит подробное описание всех функций административной панели бэкенда и веб-интерфейса.

---

## 1. Функциональные модули

Панель администратора состоит из 6 ключевых разделов:

1. **Пользователи (`/admin/users`)**
2. **Заявки на пополнение (`/admin/topups`)**
3. **История транзакций (`/admin/transactions`)**
4. **Активные смены (`/admin/shifts`)**
5. **Активные и завершенные заказы (`/admin/orders`)**
6. **Системные настройки и тарифы (`/admin/settings`)**

---

## 2. Разделы и эндпоинты

### 2.1 Управление пользователями (`UserList.vue`)

- **Просмотр списка**: Пагинация, фильтрация по ролям (`CUSTOMER`, `EXECUTOR`, `ADMIN`), статусам (`ACTIVE`, `BANNED`) и поисковой строке по телефону/имени.
- **Изменение статуса**: Блокировка/разблокировка пользователей (`POST /api/admin/users/{id}/status`).
- **Изменение роли**: Смена прав пользователя (`POST /api/admin/users/{id}/role`).
- **Ручное изменение адреса**: Редактирование адреса забора мусора у заказчиков (`POST /api/admin/users/{id}/address`).

```http
POST /api/admin/users/c7a8f9e0-1234-5678-9abc-def012345678/status
Content-Type: application/json

{
  "status": "BANNED"
}
```

### 2.2 Заявки на пополнение баланса (`TopUpRequests.vue`)

В текущей версии ручное пополнение происходит по заявкам:
- **`GET /api/admin/topup-requests?status=PENDING`** — список нерассмотренных заявок.
- **`POST /api/admin/topup-requests/{id}/approve`** — подтверждение заявки (баланс заказчика увеличивается, создается финансовая транзакция `TOPUP`).
- **`POST /api/admin/topup-requests/{id}/reject`** — отклонение заявки.

### 2.3 Мониторинг смен исполнителей (`ActiveShifts.vue`)

- **`GET /api/admin/shifts`** — отображение всех активных и завершенных смен с текущими статусами (`ACTIVE`, `COMPLETED`, `PENALIZED`).
- Индикация количества нарушений геозоны и штрафов.

### 2.4 Системные настройки (`SystemSettings.vue`)

Администратор управляет ключевыми параметрами работы приложения через `system_settings`:

| Ключ настройки | Тип | Описание |
| :--- | :--- | :--- |
| `currency` | `STRING` | Валюта отображения в приложении (`RUB`, `USD`, `EUR`). |
| `tariff_increased_mult` | `FLOAT` | Множитель тарифа «Увеличенный объем» (по умолчанию `2.0`). |
| `tariff_urgent_mult` | `FLOAT` | Множитель тарифа «Срочный (1 час)» (по умолчанию `3.0`). |
| `tariff_asap_mult` | `FLOAT` | Множитель тарифа «ASAP (15 минут)» (по умолчанию `8.0`). |
| `geofence_penalty_amount` | `FLOAT` | Сумма штрафа за нарушение геозоны смены. |
| `early_exit_penalty_amount` | `FLOAT` | Сумма штрафа за досрочное завершение смены. |
