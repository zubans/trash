# Управление аукционами и ставками (Construction Waste Bidding)

Документ описывает механизм торгов для заказов на вынос строительного мусора (`CONSTRUCTION`), в которых отсутствует фиксированная стоимость.

---

## 1. Концепция

Заказы категории **Строительный мусор** (`CONSTRUCTION`) выставляются заказчиками в виде заявок с описанием объема и фотографиями. Исполнители предлагают собственную стоимость выполнения работ через механизм ставок (bids).

```mermaid
flowchart TD
    A[Заказчик: Создает заказ CONSTRUCTION] --> B[Заказ опубликован без цены]
    B --> C[Исполнитель: Ставка POST /api/executor/orders/{id}/bids]
    C --> D[Заказчик: Список ставок GET /api/customer/orders/{id}/bids]
    D --> E[Заказчик: Принимает ставку POST /api/customer/bids/{id}/accept]
    E --> F[Холдирование средств с баланса заказчика]
    F --> G[Назначение исполнителя: Status ASSIGNED]
    G --> H[Открытие комнаты чата между участниками]
```

---

## 2. Бизнес-правила аукциона

1. **Право на ставку**: Подать ставку может только исполнитель с **активной рабочей сменой** (`ShiftStatusActive`), не по своему заказу и не при отрицательном балансе. Заказ должен быть в `SEARCHING`, а его вариант услуги — аукционным (`is_auction`); иначе `409`.
2. **Верифицированный заказчик**: список аукционов (`GET /api/executor/orders/available`), подача ставки и её принятие проходят через один и тот же предикат допуска (`service/eligibility.go`), и этот предикат требует верифицированного заказчика. Заказ неверифицированного заказчика в список не попадает, ставку по нему не подать и не принять — отдельного фильтра в списке сверх предиката нет. Тот же предикат проверяет возраст и верификацию исполнителя, тихую блокировку и скриптовые правила услуги.
3. **Сумма ставки**: Должна быть больше 0 и не больше 10 млн ₽ (`maxBidPrice`); иначе `422`.
4. **Принятие ставки** (одна транзакция в `BidService.AcceptBid`):
   - Ставка и заказ блокируются; исполнитель ставки заново проверяется тем же предикатом допуска и должен быть на смене (`ErrBidderOffShift`, `409`).
   - Принятие ставки списывает указанную сумму с основного баланса заказчика и переводит ее в `hold_amount`.
   - Если на балансе заказчика недостаточно средств (`balance < offered_price`), сервер возвращает `422 Unprocessable Entity` («недостаточно средств»).
   - Заказ переходит в статус `ASSIGNED`, исполнитель связывается с заказом.
   - Все остальные альтернативные ставки на данный заказ деактивируются.
5. **Срок жизни заявки**: Непринятые заявки на строительный мусор автоматически отменяются через **7 дней** (`CANCELED`): `AuctionWorker` раз в минуту под защитой лидера находит такие заказы и зовёт `OrderService.CancelUnclaimedAuction`.

## 3. Эндпоинты API

| Метод | Эндпоинт | Роль | Описание |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/customer/orders/construction` | `CUSTOMER`, `ADMIN` | Создать аукционный заказ. `422` — негодные данные, `403` — заказчик не допущен. |
| `GET` | `/api/executor/orders/available` | `EXECUTOR`, `MODERATOR`, `ADMIN` | Открытые аукционы, которые исполнителю разрешено видеть. |
| `POST` | `/api/executor/orders/{id}/bids` | `EXECUTOR`, `MODERATOR`, `ADMIN` | Подать ставку (`offered_price`). `201`; `404` — нет заказа; `403` — не допущен; `409` — не аукцион, не `SEARCHING`, нет смены, свой заказ, минус на балансе; `422` — сумма. |
| `GET` | `/api/customer/orders/{id}/bids` | `CUSTOMER`, `ADMIN` | Ставки по своему заказу. `404` — нет заказа, `403` — чужой. |
| `POST` | `/api/customer/bids/{id}/accept` | `CUSTOMER`, `ADMIN` | Принять ставку. `404` — нет ставки/заказа; `403` — чужой заказ или исполнитель не допущен; `409` — ставка не `PENDING`, заказ не `SEARCHING`, исполнитель не на смене; `422` — недостаточно средств. |

Коды выдаёт `writeDomainError` по классу ошибки сервиса; неизвестная ошибка — `500 internal error`.

---

## 4. Формат данных

### Запрос подачи ставки (`POST /api/executor/orders/{id}/bids`):
```json
{
  "offered_price": 2500.00
}
```

### Ответ при получении списка ставок (`GET /api/customer/orders/{id}/bids`):
```json
[
  {
    "id": "b1112223-4444-5555-6666-777788889999",
    "order_id": "c7a8f9e0-1234-5678-9abc-def012345678",
    "executor_id": "e9998887-6666-5555-4444-333322221111",
    "offered_price": 2500.00,
    "status": "PENDING",
    "created_at": "2026-08-11T14:30:00Z"
  }
]
```
